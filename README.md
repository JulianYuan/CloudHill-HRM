# 云山人力资源管理系统

> 功能完整、演示友好的企业级HRM系统，一键启动即可呈现真实业务场景

---

## 项目概述

云山HR（CloudHill HRM）是一个功能完整的人力资源管理系统，专为个人技术作品集展示设计。系统采用前后端分离架构，内置逼真的企业种子数据，启动即可体验完整的HR业务流程。

**核心特点：**

- **一键启动**：内置100+员工、10部门、2个月考勤记录等种子数据
- **技术深度**：实现考勤规则引擎、RBAC权限模型、员工状态机、薪资公式引擎
- **业务闭环**：覆盖员工入职到离职全生命周期，串联考勤、假期、薪酬
- **开箱即用**：Docker一键部署，代码结构清晰，适合开源参考

---

## 核心功能

### 🔐 系统管理与权限控制
- 用户管理（账号与员工档案关联、密码加密）
- RBAC角色管理（菜单/按钮权限配置）
- 数据权限（全部/本部门/仅本人）
- JWT认证与登录安全

### 🏢 组织人事管理
- 多层级树形部门结构
- 可视化组织架构图
- 岗位体系管理
- 员工生命周期管理（入职/转正/调动/晋升/离职状态机）

### 📊 考勤管理
- 考勤组与班次配置
- 一键打卡（上班/下班）
- 日考勤计算引擎（迟到/早退/旷工判定）
- 加班与调休管理
- 假期管理（年假/病假/事假等）
- 月考勤汇总

### 💰 薪酬管理
- 薪资结构配置
- 算薪引擎（关联考勤数据）
- 工资单管理与电子工资条

### 👥 招聘管理
- 职位管理与发布
- 人才库与简历管理
- 候选人状态流转看板
- 面试流程管理

### 📈 数据分析看板
- 组织人事分析（编制饱和度、员工结构）
- 考勤分析（异常率、加班趋势）
- 薪酬分析（人工成本趋势）
- 图表联动筛选与下钻
